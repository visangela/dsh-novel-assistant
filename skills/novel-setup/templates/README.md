# 《{{书名}}》

这是用 DeepSeek Harness「小说创作模式」预设创建的小说项目。

## 目录

- `PROJECT.md`：阶段、进度、决策日志、待确认事项
- `bible/`：架构、风格、人物、时间线、伏笔、读者/主角信息表
- `outline/`：分卷与章节细纲
- `chapters/`：正文
- `reviews/`：大纲审核、quick check、mid check、完稿检查报告

## 工作方式

1. 每个阶段结束会有一份汇报，确认后才进入下一阶段。
2. 任何影响世界观、人物命运、感情线、结局的改动，都会先给方案与代价，由你决定。
3. 设定库是唯一事实来源；正文与设定冲突时，以设定库为准。
