# 章节摘要（滚动）

> 每章落盘后追加**一行**，由 `novel-draft` 负责写。只写发生了什么，不写写得怎么样。
> 用途：写第 N 章时不必读前面所有正文——读最近 3 行，加上按伏笔编号查出来的旧行，够接住情节与暗线。

| 章 | 故事时间 | 一句话剧情 | 谁的状态变了 | 埋 / 收 |
| --- | --- | --- | --- | --- |
| 1 | | | | |

写法（照抄这四条，别自由发挥）：

1. **一句话剧情 ≤40 字**，必须含「谁想要什么、被什么挡住、结果如何」。写「赵贵逼沈砚在假账上盖印，沈砚用墨迹新旧顶了回去」，不写「沈砚与赵贵发生冲突」。
2. **谁的状态变了**：写「谁：从 X 到 Y」。受伤写部位，知道写知道什么，欠人情写欠谁。本章没人变化就写「—」。
3. **埋 / 收**只写编号：`埋 F006`、`收 F001`，两件都写就 `埋 F006；收 F001`，都没有写 `—`。
4. **改了旧章要回来改这一行**，行尾加「（改）」，并在 `PROJECT.md` 决策日志记原因。

这张表是查得动的：`grep "F001" bible/digest.md` 就能找出这条线经过哪几章。
