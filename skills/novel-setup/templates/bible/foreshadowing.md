# 伏笔登记

> 每埋一个伏笔就登记；每回收一个就更新状态。超过预定回收章还未回收的，标为「逾期」并在 quick check 中处理。

| F001 | | 第 章 | | | 隐形 / 半显 / 明示 | 第 章 | 未回收 / 已回收 / 逾期 | |

> 「当章用途」必填：删掉「将来要揭示」这层，这个物件/这句话在这一章里还起什么作用？写不出来就先别埋。
> 「显形度」默认写「隐形」：读者当章不会把它记成伏笔，只会记成场景的一部分。写成「明示」必须在备注里写理由。
