# 试笔单 · 双段同题（B 档）

> 用法：一本书只用一次，在写第 1 章之前。主代理与代笔模型各写这两段，用户读完二选一，选中的那条通道定成整本书的正文写手。
> 两段都**不是**正式稿：不写进 `chapters/`，不写「本章新增事实」注释，不往设定库里记。

## 一、你是谁

你要替一部长篇小说试写两段正文。这本书的语感基准是下面这段（摘自风格指导书第九节样段，全文另见 `bible/style.md`）：

```text
<贴 200–300 字样段原文>
```

## 二、你必须先读

```text
novel-project/bible/style.md              ← 全文，尤其第三节句法、第四节对话、第八节禁忌、第九节样段
novel-project/outline/vol-01/ch-001.md    ← 本章细纲，只读你这两段用得到的部分
novel-project/bible/characters/<name>.md  ← 出场人物：执念 / 说话方式 / 压力下的反应
novel-project/bible/facts.md              ← 这两段会用到的度量与账目口径
novel-project/bible/timeline.md           ← 本章对应行
```

## 三、第一段：开场钩子（700–900 字）

```text
写什么：<细纲「冲突与推进」第 1–2 段>
写到哪停：<例如「停在赵贵把半页旧草账挑进炭盆」>
必须出现：<3 个可触摸物象>
不许：交代前史、写人物心里想什么、把后面的反转提前用掉
```

## 四、第二段：中段推进（700–900 字）

```text
写什么：<细纲「冲突与推进」第 3–4 段的前半，纯执行段，没有大钩子>
写到哪停：<例如「停在沈砚闭眼拨下第一颗算珠」>
为什么考这段：开场靠手艺，中段靠耐力。只会写开场的，这一段会散、会空、会开始解释。
必须出现：<至少 1 处「说的和想的不一样」的对话>
```

## 五、硬约束（两段都适用）

```text
第一行：`## 段一` / `## 段二`，不要写章节标题
视角：<第三人称限知，贴紧主角，不写别人心里想什么>
句法：<单句上限、段落上限，照 style.md 第三节抄>
对话：<提示语规则、每人说话差异，照 style.md 第四节抄>
禁用：<style.md 第八节禁忌清单，逐条抄>
可核对事实：数字、度量、账目只能取自 bible/facts.md 与细纲；表里没有的写〔待定：用途〕
```

## 六、输出

```text
L1：写进 reviews/draft-trial/L1-opening.md 与 reviews/draft-trial/L1-scene.md 两个文件，各 700–900 字。
L3：主代理写 reviews/draft-trial/L3-opening.md 与 reviews/draft-trial/L3-scene.md。
两份都不进 chapters/，不写 HTML 注释账本，不改任何设定文件。
```

## 七、验收三条硬线（主代理收到稿先量这三项）

```text
字数：700–900 汉字，两段都要。少于 700 退回，说清少了哪一拍，不许主代理替它补
对话占比：35%–45%（引号内汉字 ÷ 全段汉字）
停止点：必须停在试笔单写的那个位置。提前把本章高潮用完，等于把第 1 章最贵的东西花在试笔上
```

## 八、交稿前自检

```text
1. 第二段有没有开始解释人物动机？（有就删）
2. 段末是不是停在具体动作或半句话上？
3. 每个人说的话，换给另一个人还成立吗？（成立说明没写出人物）
4. 有没有出现 style.md 第八节禁用的词或句式？
5. 两段里的数字，能在 facts.md 找到出处吗？
```
